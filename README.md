# Студия: Контент-завод + Лаборатория сайтов

Одно приложение в браузере (на Mac, потом на сервере) с двумя равноправными цехами. Переключатель вверху слева —
с плавным переходом; у каждого цеха своё оформление.

- **Контент-завод** — ролики 9:16 для соцсетей: тренды → изделие → сценарист → кадры с контролем качества → монтаж → тексты → оценка → вкус.
- **Лаборатория сайтов** — сайты и лендинги: бриф → ресёрч → концепции → фото → промпты для Claude Code / Codex → сборка и проверка.

## Ниши и направления

Внутри каждого цеха — свои проекты:

- **Ниши завода** (ювелирка, косметика, мебель…). У каждой ниши свой контекст (что продаём, аудитория, тон,
  что нельзя менять в товаре, как показывать товар в деле, стиль рекламы), свой профиль вкуса, свои оценки,
  свой ресёрч трендов и свои изделия. При создании ниши ИИ сам заполняет технический контекст для нейросетей по описанию.
  Все агенты ниши (сценарист, контролёр, монтажёр, автор текстов, фото для финала) работают в её контексте.
- **Направления лаборатории** (клиники, рестораны, лендинги для экспертов…). У направления свой контекст
  (какие сайты, для кого, стиль, правила), свой вкус и свои сайты.

Переключение — карточками на главной цеха или выпадающим списком в боковой панели. Старые данные при первом
запуске сами переносятся в нишу «Ювелирка» и направление «Все сайты» (копированием, ничего не удаляется).

Настройки разделены на вкладки: «Общие» (Claude, ключи, лимит, сервер), «Контент-завод», «Лаборатория сайтов».

## Кто что делает

| Агент | «Мозг» по умолчанию | Что делает |
|---|---|---|
| Ресёрчер трендов | Claude по подписке (поиск в интернете) + Gemini (смотрит ролики) | раз в неделю собирает бриф: тренды, хуки, идеи кадров, свет, музыка, что делают конкуренты |
| Паспорт изделия | Gemini | по фото описывает кольцо одной фразой для промптов |
| Сценарист | Claude | смотрит фото, бриф трендов и профиль вкуса → концепты по 3 кадра |
| Генератор | fal.ai: Kling, Seedance, Veo, Nano Banana 2 | делает клипы; квадратные фото сначала превращает в кадр 9:16 |
| Контролёр | Gemini (или Claude по кадрам) | сверяет кольцо в клипе с фото; брак переделывается автоматически |
| Монтажёр | Claude план + FFmpeg | 2 разные версии: порядок, длина кадров, переходы, музыка, плашка |
| Тексты публикаций | Claude | VK, Telegram, YouTube + ссылки с UTM и строка маркировки рекламы |
| Куратор вкуса | Claude | обновляет профиль вкуса по твоим оценкам |

Роли переключаются в «Настройках → Кто какую работу делает». Если Claude недоступен или упёрся в лимит подписки,
задача сама уходит на Gemini (и наоборот).

## Запуск на Mac

1. Один раз в «Терминале»:
   ```
   brew install python@3.12 ffmpeg
   curl -fsSL https://claude.ai/install.sh | bash
   claude
   ```
   Если `claude` не находится: `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc`.
   Команда `claude` открывает Claude Code — войди своим аккаунтом с подпиской (Pro/Max) и выйди (`/exit`).
2. Двойной клик по `start.command` (если macOS ругается: правый клик → «Открыть»).
3. Откроется `http://localhost:8765`. В «Настройках → Claude по подписке» нажми «Проверить Claude».

## Лаборатория сайтов (второй цех)

Меню слева → «Лаборатория сайтов» → «Новый сайт».

1. **Бриф:** название и/или логотип, сфера, лендинг или полноценный сайт (сколько и какие страницы), главное действие,
   сайты, которые нравятся, пожелания, технология (HTML/CSS — собирается и смотрится прямо здесь; Next.js — статический;
   Next.js с сервером — для оплаты и заявок).
   **Запуск: боевой сайт** — галочка «Готов к запуску»: кто продаёт (ИП/ООО/самозанятый, налог, НДС в чеке), что и как продаём,
   онлайн-оплата (ЮKassa, Т-Банк, CloudPayments, Robokassa или другой сервис), чеки 54-ФЗ, куда идут заявки (Telegram/почта),
   Метрика, юр. страницы, реквизиты. Технология сама переключается на «Next.js с сервером».
2. **Бренд-кит:** цвета измеряются по логотипу, Claude добавляет роли цветов, шрифты Google Fonts с кириллицей, тон.
3. **Ресёрч:** Claude ищет 8–10 сайтов (лидеры сферы + эталоны дизайна), тренды дизайна и фото-тренды (какие фото сейчас в хайпе и что выглядит дёшево), прототип снимает скриншоты (Playwright),
   Claude разбирает их глазами: что сильно, что слабо, что взять, чем выделиться.
4. **Концепции:** 3 разных направления с палитрой, шрифтами, картой страниц и живым превью первого экрана. Выбираешь одно, можно с правками словами.
5. **Фото и видео:** фотодиректор по концепции и фото-трендам из ресёрча задаёт единый фотостиль и список мест под фото
   (hero, команда, услуги…). Каждое место: «Сгенерировать» (Nano Banana 2, ~$0.12), «Своё фото» или загрузка пачкой
   и «Разложить мои фото по местам» (Claude смотрит фото и подбирает места), «Ретушь» и «Как с фотосессии» —
   ИИ доводит своё фото до уровня профессиональной съёмки, сохраняя людей и предметы. Выбранные фото уходят
   в пакет промптов и в сборку (`assets/photos` + `PHOTOS.json` с alt-текстами).
   **Видео:** места под видео (фон первого экрана, процесс, товар в деле) предлагает фотодиректор, можно добавить своё.
   Своё видео (mp4/mov/webm) готовится для сайта (H.264, до Full HD, без звука, постер), дальше — «Цвет и резкость» (бесплатно),
   «Качество ×2» (Topaz, ~$0.02/с), «Как дорогая съёмка» (Kling O3, $0.168/с) или «Видео из фото» (Kling 3.0, $0.112/с).
   Выбранные видео уходят в сборку (`assets/videos` + `VIDEOS.json`).
6. **Промпт:** пакет для Claude Code / Codex — `MASTER.md` (он же `CLAUDE.md`/`AGENTS.md`: дизайн-система, компоненты, техника,
   критерии готовности), промпт на каждую страницу с точными текстами, `CONTENT.md`, `PHOTOS.md`, `CHECKLIST.md`, `ALL_IN_ONE.md`;
   у боевого сайта ещё `INTEGRATIONS.md` (оплата, чеки, заявки, аналитика), `LEGAL.md` (шаблоны юр. страниц) и `LAUNCH.md` —
   пошаговая инструкция, что сделать руками (договор с платёжным сервисом, чеки, ключи в `.env`, вебхук, Роскомнадзор).
   **Правки по пожеланиям:** пишешь словами, что поменять, — Claude Code по карте пакета находит нужные файлы и правит только
   их (1–3 минуты вместо полной перегенерации). Перед каждой правкой пакет сохраняется — любую правку можно откатить.
7. **Сборка:** Claude Code по подписке собирает сайт (журнал действий виден в окне задачи), затем снимает десктоп и телефон
   и проверяет себя по чек-листу. «Исправить замечания» и правки своими словами — новая итерация в той же версии; «Собрать новую версию» — с нуля.
   Оценки концепций и сборок копятся во «вкус сайтов».

Кнопка «Подготовить концепции» проходит шаги 2–4 одной кнопкой. Сгенерированные страницы открываются в изолированной
песочнице и не имеют доступа к админке.

## Финальный кадр

Вкладка «Ролики» → «Финальный кадр»: Nano Banana 2 по фото изделия снимает рекламное фото кольца в выбранной сцене
(бархат, травертин, шёлк, чёрное зеркало, лепестки) с местом под надписи, сверху ложится типографика — макеты
«Журнал», «Арка», «Минимал», четыре цвета надписей, слоган (Claude может предложить варианты), цена, промокод, призыв.
Можно загрузить своё фото. Кадр держится 3 секунды в конце каждого ролика.

## Библиотека съёмки

Фото и видео изделий лежат в папке `library/` проекта (бывшая «По изделиям»): внутри по папке на изделие.
На вкладке «Изделие» кнопка «Выбрать из библиотеки»: поиск по номеру папки или артикулу, отмечаешь нужные фото
и одно видео. Новую съёмку клади новой папкой в `library/`.

Данные изделия лежат в его папке, в `library/<N>/product.json`. При выборе папки карточка заполняется из этого файла.
Непустые поля заменяют то, что было в карточке; если названия нет, берётся артикул.

```json
{
  "article": "8040200П-40",
  "name": "Цепь «Бисмарк», красное золото",
  "brand": "MOROZ JEWELLERY",
  "price": "24 900 ₽",
  "promo": "MOROZ10",
  "link": "https://…",
  "description_ru": "Описание как на сайте",
  "visual_en": "Паспорт для нейросетей: одна фраза по-английски"
}
```

Заготовки созданы для всех папок: бренд и артикул (где его удалось понять из имён файлов) уже вписаны,
остальное заполни сам. `product.json` хранится в git обычным текстом, не в LFS.

Библиотека хранится в git через **Git LFS** (`.gitattributes`). Перед клонированием один раз: `brew install git-lfs`
(на сервере `sudo apt install git-lfs`), затем `git lfs install`. Если папка оказалась с «заглушками» вместо фото —
`git lfs pull`. Другую папку можно указать в «Настройках → Библиотека съёмки».

## Одна кнопка

На странице изделия — «Сделать ролики»: паспорт → концепты → кадры (с контролем и переделкой брака) → по 2 версии
монтажа на концепт. Перед запуском показывается оценка, дневной лимит трат защищает от сюрпризов.
Всё то же можно делать по шагам вкладками «Изделие → Сценарий → Кадры → Ролики».

## Режимы

- **Демо** — клипы собираются из твоих фото через FFmpeg, $0. Агенты (Claude/Gemini) при этом работают по-настоящему.
- **Боевой** — ключ fal.ai в «Настройках» и снять галочку «Демо-режим».

## Тренды недели

Страница «Тренды недели»: задание ресёрчеру (ниша, аудитория, конкуренты, ключевые слова), ссылки на YouTube-референсы,
загрузка скачанных роликов. «Запустить ресёрч» → 3–10 минут → бриф становится активным и попадает к сценаристу,
монтажёру и автору текстов. По желанию — сборщики Apify (токен в «Настройках»).

## Где что лежит

```
content-factory/
  start.command        запуск на Mac          deploy/   запуск на сервере (см. SERVER.md)
  .env                 ключи и настройки (создаётся сам, права 600)
  app/factory/         агенты: brains (Claude/Gemini), research, llm (сценарист, контролёр), gen, montage, publish
  library/<N>/         библиотека съёмки «По изделиям»: фото и видео изделия (Git LFS)
  data/products/<id>/  всё по изделию: фото, клипы, ролики, product.json
  data/research/       задание, брифы, референсы и их разборы
  data/library_thumbs/ превью библиотеки «По изделиям» (кеш, можно удалить)
  data/music/          треки для монтажа: CC0 / общественное достояние (Git LFS), источники в LICENSES.md
  data/costs.jsonl · data/ratings.jsonl · data/taste.md
```

## Если что-то не так

- **Claude «не подключён»** — в Терминале `claude`, войди; затем «Настройки → Обновить статус».
  Если `claude` не находится, укажи путь (обычно `~/.local/bin/claude`) в «Настройках».
- **«исчерпан лимит подписки»** — задача ушла на Gemini; можно поставить модель Claude «Sonnet», она тратит лимит медленнее.
- **Ошибка fal.ai** — ключ и баланс в кабинете fal.ai. Текст ошибки — в окне задачи справа внизу.
- **Ошибка Gemini 503/429** — перегрузка или лимит бесплатного тарифа: завод сам повторяет и пробует другие модели.
- **Монтаж** теперь проверяет длину готового ролика и при сбое пересобирает его простой склейкой.

## Что не хранится в репозитории

`.env` (ключи), `.venv` и папка `data/` (изделия, ролики, оценки, профиль вкуса, ресёрч) — см. `.gitignore`.
Библиотека `library/` и музыка `data/music` в репозитории есть, но файлы лежат в Git LFS (`.gitattributes`):
перед клонированием `git lfs install`. После клонирования: запусти `start.command`, ключи вставь в «Настройках».
